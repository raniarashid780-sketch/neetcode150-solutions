## Repo structure

Each category is a folder. Each problem is a **pair of files**: `NNN_problem_name.py`
(the solution) and `NNN_problem_name.md` (the write-up). The `.md` is mandatory —
no write-up, no commit. Every write-up covers: the problem restated in my own words,
brute force approach + complexity, optimal approach + complexity + the actual insight,
and what I got wrong on the first attempt.
